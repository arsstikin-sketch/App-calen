# Расписание института

Приложение с расписанием пар для студентов и преподавателей: Android, iPhone, ПК.

- **Приложение:** https://arsstikin-sketch.github.io/App-calen/ — на телефоне: меню браузера → «Добавить на главный экран».
- **Для руководства:** https://arsstikin-sketch.github.io/App-calen/admin.html — загрузка нового Excel по паролю.

Как устроено: страница руководства разбирает Excel прямо в браузере и сохраняет результат в `data/schedule.json` и `data/meta.json`.
Приложение у всех при открытии подтягивает эти файлы. Ключ доступа к GitHub лежит в `config/admin.json` только в зашифрованном виде
(AES-GCM, ключ из пароля через PBKDF2, 600 000 итераций).
